🌐 G4F Custom Server — reference implementation

A working re-implementation of the gpt4free/g4f.dev custom-server feature (the #custom:srv_… flow). Pick a server + model and chat — exactly like https://g4f.dev/chat/, but against a local router.

Hi! I'm the reference router. Pick a provider + model above and say something — streaming works too.
How this mirrors g4f.dev: the browser calls POST /custom/{srv_id}/chat/completions (with your g4f_session as Bearer token); the router looks the server up in the public index / your private servers, picks a random key from the owner's key pool, proxies to the upstream (here: a local mock of cakey's osaii.wyvernhub.net relay), streams SSE back, and records usage. See ../01-ARCHITECTURE.md for the full deep dive.
