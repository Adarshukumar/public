# route-web — the frontend (3rd route folder)

The chat UI: `index.html` (page shell) + `app.js` (model list, search, SSE
streaming renderer, collapsible 🧠 thinking box, stop/new-chat) +
`style.css` (dark g4f-inspired theme).

Served by the backend in [`../route-py/`](../route-py/) on the same port —
no separate dev server needed.

Full documentation: [`../README.md`](../README.md)
